# bienvuimmo

## 🚀 Démarrage

### Terminal 1 - Backend API
```bash
cd backend
npm run dev
```
API: http://localhost:4000

### Terminal 2 - Frontend
```bash
cd frontend
npm run dev
```
Web: http://localhost:3000

## ✅ Structure mise en place

**Frontend** (`/frontend`)
- Next.js 14 + React 18
- Tailwind CSS
- Page d'accueil moderne
- Prêt à consommer l'API

**Backend** (`/backend`)
- Express + TypeScript
- Prisma ORM
- Routes API structurées
- Schéma DB complet (12 modèles)

## 📝 Endpoints disponibles

- `GET /api/health` - Status de l'API
- `GET /api/properties` - Liste des biens
- Routes auth, contacts, mandates... (à implémenter)
